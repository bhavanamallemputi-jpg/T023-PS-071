# Library Circulation Engine with Holds, Fines and Inter-Library Loans

## Project Information

- **Team ID:** T023
- **Problem Statement:** PS-071
- **Programming Language:** Python 3.10+

## 1. Project Overview

The Library Circulation Engine is a Python-based application developed to manage library operations such as issuing books, returning books, renewing loans, managing holds, calculating fines and handling inter-library loans.

The system processes library commands according to the business rules provided in the project requirements.

## 2. Project Objectives

- Manage library book circulation.
- Maintain member borrowing records.
- Calculate overdue fines.
- Manage book reservations and hold queues.
- Handle lost and damaged books.
- Process inter-library loan requests.
- Generate circulation reports.
