# Library Circulation Engine – Glossary

| Term | Meaning |
|---|---|
| Member | A person registered with the library. |
| UG | Undergraduate student. |
| PG | Postgraduate student. |
| RESEARCH | Research scholar. |
| FACULTY | Teaching staff member. |
| EXTERNAL | External library member. |
| Title | A book or other library resource. |
| Copy | An individual physical copy of a title. |
| Issue | Lending a library copy to a member. |
| Return | Returning an issued library copy. |
| Renewal | Extending the loan period. |
| Hold | Requesting a title that is currently unavailable. |
| Fine | Money charged for returning an item late. |
| Lost Item | An item that has not been returned within the allowed period. |
| Damaged Item | An item returned in damaged condition. |
| Inter-Library Loan (ILL) | Borrowing an item from another library. |
| Due Date | The date by which an item must be returned. |
| Ledger | A record of charges, payments and refunds. |
| Recall | Requesting an issued item back because another member needs it. |
| Partner Library | Another library participating in inter-library loans. |
